Overall average recapture time

Recapture time uses the first recorded appearance as the initial tagging date. Each later capture date contributes one interval, measured from that first date. The average weights all recapture events equally; a tag recaptured on several dates contributes several intervals. Tags with no recapture are excluded.

One tag seen several times on one date counts once. Recaptures require the same ArUco identity on a later date; n8tags do not count as recaptures. Outside-domain and unassigned appearances are excluded. The 27 unconfirmed n8tag appearances remain included in tagging totals. Tag identity does not independently prove biological identity.

Master capture history CSVOne row per tag: ID, bee number, first assignment date, recapture flag and ordered recapture dates

Dates use YYYY-MM-DD. tag_id retains the aruco: or n8tag: prefix. The second column, bee_number, gives the within-day bee number on the first assignment date; multiple numbers on that date are separated by semicolons, for example 9;10. first_assignment_date is the first recorded appearance of that ID. recaptured is true if the tag has a later ArUco recapture, otherwise false. recapture_1_date, recapture_2_date and subsequent columns list distinct later dates in order; unused cells are blank. All included tag IDs are retained, including tags never recaptured.
